# Universal Assistant Application (3rd Year Project)

## How to run:
## Method 1: APK
Download "app_debug.apk" from [Release](https://github.com/Jeothish/Universal-Assistant-Application/releases/tag/v1.0) and transfer to android device.

On android device install the transferred APK (app downloads from untrusted sources needs to be enabled in settings), App will install and can be run. on phone.

## Method 2: From source
Clone repo in Android Studio

The llm "Qwen2.5-1.5B-Instruct_multi-prefill-seq_q8_ekv4096.litertlm" from [Release](https://github.com/Jeothish/Universal-Assistant-Application/releases/tag/v1.0) is used in the project. The chat functionality will not work without it. Please download this and move it to -> "MyApplication/app/src/main/assets" in Android studio as this file is too large to be stored directly in the repo.

build and run with an android phone connected to computer on Android Studio

## LLM DOWNLOAD

Download LLM from [Repo Release page](https://github.com/Jeothish/Universal-Assistant-Application/releases/tag/v1.0) OR [here](https://huggingface.co/litert-community/Qwen2.5-1.5B-Instruct/blob/main/Qwen2.5-1.5B-Instruct_multi-prefill-seq_q8_ekv4096.litertlm) and move to [assets](MyApplication/app/src/main/assets) (in Android Studio). As this file is too large to be stored in the repo directly.
